```
jaiproductions-website/
├── index.html          # Complete single-page website (all CSS/JS inline)
├── og-image.png        # Open Graph social preview image (1200x630px)
├── robots.txt          # Search engine crawl instructions
```

## The Site in One Line

Dark industrial aesthetic, amber (#e8960a) accents, single-page with anchor navigation. All CSS and JavaScript are inline in index.html. No backend, no CMS, no database.
