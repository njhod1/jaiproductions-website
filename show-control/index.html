JAI Productions / Show Control

Show control, PLC & media networking

Show control architecture, PLC and SCADA systems, and the media networks that connect them — designed, commissioned and kept running across touring productions, immersive exhibitions and themed entertainment.

What I deliver

Show control is where artistic intent becomes technical scope. I build and commission the control layer, then make sure the network underneath it stays invisible to the audience.

  • Show control — Alcorn McBride, Medialon, Beckhoff, DMX, MIDI, CANbus
  • PLC and SCADA systems — PLC & SCADA Systems Certificate, Engineering Institute of Technology (2011)
  • TAIT Navigator — automation platform training (2019)
  • Media networking — NDI video, Dante audio, SMPTE ST 2110 IP media transport, Q-SYS, multi-node media delivery
  • AV/IT integration — Cisco and Meraki switching, managed VLAN environments, Windows Server and Active Directory
  • Show creation — show files, cue stacks and RF workflows built from zero, with operators trained by opening night
  • Documentation — network diagrams, commissioning checklists and SOPs

Where it has been applied

Jurassic World: The Exhibition ran a control architecture spanning Alcorn McBride, Medialon, Beckhoff, servo and hydraulic systems, PID motion control, Dante media distribution and Cisco IT infrastructure across concurrent international venues. Metaverse of Magic (2023–2024) needed a stable NDI, LED and wireless media network in a high-RF live environment, and Titanique (2024–2025) was built from script edit to opening night.
